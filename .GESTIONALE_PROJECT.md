# Gestionale Paola - Progetto Quarkus

**Repository:** `saas-gestionale`

## Stack Tecnologico
- **Framework:** Quarkus 3.39.5
- **Linguaggio:** Java 21
- **Database:** PostgreSQL (produzione), H2 (dev/test)
- **ORM:** Hibernate ORM Panache
- **Migrazioni:** Liquibase 4.20.0
- **Build:** Maven con wrapper

## Struttura del Progetto

```
src/main/
├── java/com/pirris/
│   ├── GreetingResource.java         # Endpoint REST starter
│   └── MyEntity.java                 # Entity starter example
└── resources/
    ├── application.properties        # Configurazione Quarkus
    ├── db/
    │   ├── schema.sql                # Schema DB generato
    │   └── changelog/
    │       └── db.changelog-master.xml  # Liquibase migrations
    └── import.sql
```

## Database (14 tabelle Liquibase)

| Tabella | Descrizione |
|---------|-------------|
| `training_service` | Servizi di training offerti |
| `service_rate` | Tariffe e durate per servizio |
| `client` | Anagrafica clienti con note mediche |
| `client_appointment_preference` | Preferenze orarie ricorrenti |
| `training_session` | Appuntamenti individuali/gruppo |
| `lesson_package` | Pacchetti lezioni prepagati |
| `session_participant` | Partecipanti alle sessioni |
| `package_use` | Tracciamento utilizzo pacchetti |
| `ledger_entry` | Movimenti contabili (entrate/uscite) |
| `unavailability` | Blocco calendario trainer |
| `invoice` | Fatture clienti |
| `expense` | Spese aziendali/personali |
| `course` | Corsi settimanali di gruppo |
| `course_participant` | Iscrizioni ai corsi |
