Sviluppatore Java con progetto "Gestionale Paola" - un'applicazione SaaS per la gestione di un'attività di training/palestra.

**Stack tecnologico preferito:**
- Quarkus 3.x per applicazioni Java
- Hibernate ORM Panache per la persistenza
- PostgreSQL come database principale
- Liquibase per le migrazioni
- Maven per il build

**Nota:** Il progetto ha uno schema database molto completo (14 tabelle) definito con Liquibase, ma le entity Java devono ancora essere create per mappare le tabelle del database.

**Convenzioni del progetto:**
- Package: `com.pirris`
- Entity Panache con UUID come PK
- Migrazioni versionare in Liquibase
- Profili Quarkus: dev (H2), test (H2 in-memory), prod (PostgreSQL)
