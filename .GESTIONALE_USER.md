Sviluppatore Java con progetto "Gestionale Paola" - backend per un'attività di
personal training, a servizio dell'app nativa SwiftUI `paola_gestionale`.

**Stack tecnologico preferito:**
- Quarkus 3.x per applicazioni Java
- Hibernate ORM Panache (active record) per la persistenza
- PostgreSQL come database principale (H2 per dev/test)
- Liquibase per le migrazioni
- Maven per il build

**Convenzioni del progetto:**
- Package: `com.pirris`
- Entity Panache con suffisso `Model`, PK UUID, nel package `model`
- Resource REST come interfaccia + implementazione `*ResourceImpl`, nel package `resource`
- Enum di dominio tipizzati, persistiti via `AttributeConverter`
- Migrazioni versionate in Liquibase (schema di proprietà di Liquibase, non Hibernate)
- Profili Quarkus: dev (H2 file), test (H2 in-memory), prod (PostgreSQL)

**Preferenze di lavoro (emerse):**
- Backend orientato ai casi d'uso / view dell'app, non uno specchio del DB.
- Smagrire e normalizzare: eliminato ledger e tabella consumo pacchetti (contabilità e
  crediti derivati); rimosse colonne denormalizzate; corsi trattati come sessioni.
- In sviluppo: nessuna retrocompatibilità, lo schema si può riscrivere liberamente.
- Mai eseguire `git commit`/`git push` per suo conto (vedi memoria `never-commit-or-push`).
